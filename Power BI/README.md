# 📊 Power BI Projects

This folder contains my Power BI dashboard projects.

## Project 1: Superstore Sales Analytics Dashboard

### Objective
Analyze Superstore sales data and identify business insights using interactive dashboards.

### Tools Used
- Power BI
- DAX
- SQL
- Microsoft Excel

### Key Insights
- West region generated the highest sales.
- Technology category produced the highest profit.
- Consumer segment contributed the highest sales.
- Furniture had the highest average discount.
- Identified loss-making products worth over $76K.

### Dashboard Features
- KPI Cards
- Interactive Slicers
- Monthly Sales Trend
- Regional Analysis
- Category Analysis
- Customer Segment Analysis
- Loss-Making Products Tracker
